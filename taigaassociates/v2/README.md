# 年輪ラインアート / TAIGA ASSOCIATES

> **version 2 — 作業中**
> 現行の開発版です。凍結済みの version 1 は `../v1/` にあります。

ウェブサイトのブロック内で使う、パラメーター駆動のジェネラティブ線画アート。
樹木の断面をモチーフに、年輪をフラットで力強いグラフィックとして描きます。
WebGL1 のみで動作し、外部ライブラリ依存はありません。

## ファイル構成

| ファイル | 役割 | 誰が使うか |
|---|---|---|
| `nenrin-runtime.js` | 描画エンジン本体。設定を渡すと描画し、設定間の遷移も行う | 実装者（本番に配置） |
| `nenrin-lineart-tester.html` | アートを作り込むオーサリングツール。設定の書き出しもここから | デザイナー |
| `nenrin-embed-demo.html` | 組み込み例・遷移の動作確認 | 両方 |

テスターは `nenrin-runtime.js` を読み込んで動くので、**プレビューで見たものが本番で動くものと同一**です。同じフォルダに両方を置いてください。

## v1 からの変更

**廃止したもの**

- 重なり（複数レイヤー）— 設定は1枚のアートを表すフラットなオブジェクトになりました（`layers` 配列はありません）
- 立体表示 — 3Dチルト、パース、3D回転、螺旋の奥行き、メビウス状の揺らぎ
- Z軸での回転 — 自動回転、リング毎のひねり、ひねりの回転
- 立体形状とそのプリセット — 球体、螺旋チューブ、メビウス面、キューブ、インフィニティ、トーラスノット、ウェーブ、スプリング、回転、ミラーほか

**追加・変更したもの**

| 項目 | 内容 |
|---|---|
| 線幅（最外周） | 0.2〜30。太いフラットな線も描けます。線の縁はピクセル単位で解決するので、太くてもシャープです |
| 中心の線幅 `lineWidthInner` | 最外周を1とした中心の線幅。0.12 なら中心ほど細く、外側ほど太くなります |
| 線幅の変化 | 下記「線幅の変化」の4系統 |
| 外形のうねり `outlineAmt` / `outlineFreq` / `outlineGrowth` | 全リングが共有する大きなうねり。外側ほど大きくなるので、中心は丸く外周はいびつな、樹木の断面らしい形になります |
| 中心のアイコン `icon` / `iconAmt` | 任意の SVG を中心に置けます（下記） |
| 線種 | ブラー・インク・水彩を太い線向けに作り直しました |
| スケール | 線幅もスケールと一緒に拡大縮小します（SVG の線と同じ扱い）。ブロックの大きさが変わっても比率が保たれます |

v1 で書き出した JSON（`{ global, layers }` 形式）も読み込めます。最初の層だけが使われ、3D 関連の項目は無視されます。

## 実装者向け：使い方

```html
<div class="art-block" style="position:relative;width:100%;height:100vh">
  <canvas id="art" style="position:absolute;inset:0;width:100%;height:100%"></canvas>
</div>

<script src="nenrin-runtime.js"></script>
<script src="my-arts.js"></script>   <!-- テスターから書き出した設定 -->
<script>
  var art = NenrinArt.create(document.getElementById('art'), artA);

  // 別のアートへシームレスに繋ぐ
  art.transitionTo(artB, { duration: 1400, force: true, stage: false });
</script>
```

設定は1枚のアートを表すフラットなオブジェクトです。記載のない項目は `NenrinArt.defaultConfig()` の既定値で補われるので、テスターの書き出しには既定値と違う項目だけが入ります。

```js
var artB = {
  bgColor: '#eef2f6',
  color: '#3a5f8a',
  lineWidth: 3.2,
  lineWidthInner: 0.3,
  outlineAmt: 105
};
```

canvas は CSS で好きなサイズにしてください。解像度・DPR・リサイズはランタイムが自動追従します。

## 線幅の変化

線幅は次の掛け算で決まります。すべてシェーダーで計算されるので、遷移で補間されます。

| 系統 | パラメータ | 効果 |
|---|---|---|
| 中心 → 外側 | `lineWidthInner`, `lineWidthCurve` | 中心の線幅（最外周比）と、そこへ至るカーブ。カーブ 1 未満は中心寄りで変化、1 超は外周寄りで変化 |
| リズム | `widthAccentEvery`, `widthAccentAmt` | 外周から N 本ごとの年輪を太く（0=なし）。外周から数えるので最外周は必ず強調されます |
| 方向の抑揚 | `widthDirAmt`, `widthDirAngle` | 片側を太く、反対側を細く。角度は 0=右・90=下・270=上 |
| 筆圧のゆらぎ | `widthNoiseAmt`, `widthNoiseFreq` | 1本の線の途中で太さが揺れる。近い年輪どうしは似た揺れ方をします |
| ばらつき | `ringWidthVar` | 1本ずつのランダムな差 |

## 中心のアイコン

`icon` に入るのは、M / L / Z だけでできたパス文字列です（例: `'M0 1 L-0.012 0.989 ... Z'`）。アイコンの重心が原点、最も遠い点が半径1になるよう正規化済みです。テスターで SVG を読み込むと、この形に変換されて書き出しにもそのまま入ります。

ページ側で SVG から変換したい場合は `NenrinArt.svgToIcon()` を使います（ブラウザ上でのみ動作）。

```js
var icon = NenrinArt.svgToIcon('<svg viewBox="0 0 24 24"><path d="..."/></svg>');
var art = NenrinArt.create(canvas, { icon: icon, baseRadius: 90 });
```

- **大きさは `baseRadius`** — アイコンは基準半径の大きさで描かれます
- **各リングはアイコンの「平行なオフセット」** — 拡大コピーではなく、アイコンから一定距離ずつ外へ膨らませた形です。そのためハートのくぼみは外へ行くほど埋まり、先端は丸くなり、十分外側では自然に円になります
- `iconAmt` で円との間を連続的に変えられます（遷移で補間されます）
- rect / circle / polygon / path、グループの transform、viewBox はすべてブラウザ自身が解決します。`<script>` やイベント属性は読み込み時に取り除かれます
- 中心から放射状に見て外形を取るため、「C」の字のような深く凹んだ形は外側の輪郭として扱われます。シンプルなアイコン向けです

## アート間の遷移

`transitionTo()` は3つの方式を使い分けます。

| 方式 | 条件 | 見え方 |
|---|---|---|
| **morph** | 構造パラメータが一致 | 形状そのものが連続変形 |
| **forced**（`force: true`） | 構造が異なる | ほぼ全編モーフ。終盤だけ短く実体を入れ替え |
| **crossfade** | 構造が異なり `force` なし | 両方を同時描画して不透明度で入れ替え |

### 構造パラメータ（これが一致すると morph になる）

```
ringCount, segments, spiralBlend, spacingVarFreq, seed, icon
```

この6項目だけが頂点バッファに焼き込まれます（`NenrinArt.STRUCTURAL_KEYS`）。それ以外の数値・色はすべてシェーダーで補間されます — 線幅、中心の線幅、外形のうねり、アイコンの効き、基準半径、間隔、偏心なども含みます。

### 動きを落ち着かせる

| オプション | 効果 |
|---|---|
| `stage: false` | スケール・位置（`scale` / `offsetX` / `offsetY`）を現在の値のまま固定し、形の変化だけを見せる |
| `calm` | 遷移中に残す常時アニメーションの量。`0` で静止、`0.15` が既定、`1` で通常どおり |

`calm` は振幅ではなく**時間の進み方**を落とす実装なので、遷移の前後で位相が飛ぶことはありません。速度パラメータ（`wobbleSpeed` ほか）も経過時間との掛け算ではなく毎フレーム積算した位相なので、速度を補間しても角度が一気に振れることはありません。

## API

```js
var art = NenrinArt.create(canvasEl, config, {
  onStats: fn,                 // ({ rings, verts }) を受け取る
  calm: 0.15,                  // これ以降の遷移の既定値
  stage: true
});

art.transitionTo(config, {
  duration: 1200,              // ms
  easing: 'easeInOutCubic',    // linear | easeOutCubic | easeInOutQuad | easeInOutCubic | 関数
  force: false,                // 構造が違ってもモーフで繋ぐ
  calm: 0.15,
  stage: true,                 // false でスケール・位置を固定
  onComplete: fn
});                            // -> 'morph' | 'forced' | 'crossfade'

art.setConfig(config);         // 即時切り替え（アニメーションなし）
art.getConfig();               // 現在の設定を複製して取得
art.cancelTransition();
art.isTransitioning();
art.renderNow();               // canvas.toDataURL() の直前に呼ぶ
art.destroy();                 // rAF停止・リスナ解除・GPUバッファ解放

NenrinArt.defaultConfig();     // 既定値
NenrinArt.normalizeConfig(c);  // 既定値で補完（v1 形式も変換）
NenrinArt.canMorph(a, b);      // true なら morph で繋がる
NenrinArt.svgToIcon(svgText);  // SVG -> icon 文字列
```

`art.state` は生きた設定オブジェクトです。直接書き換えれば次のフレームに反映されます（スクロール連動などに）。構造パラメータを変えた場合は `art.regen()` が必要です。

## デザイナー向け：テスターの画面構成

サイドバーは3つのタブに分かれています。

| タブ | 内容 |
|---|---|
| **アート** | プリセットと、アートのパラメーター |
| **シーン** | シーンの保存・切り替えと遷移の設定 |
| **書き出し** | 実装用コードの書き出し・JSON での保存と復元 |

アートタブのパラメーターは、目的別のセクション（色 / 線 / 線幅の変化 / 年輪の構成 / 中心のアイコン / 外形のうねり / 細かな揺らぎ / 動き / マウス・変形 / 配置）に分かれていて、見出しをクリックで開閉できます。

- 閉じていても、見出しの右に要点（線種と線幅、本数など）が表示されます
- **読み込んだ状態（プリセット・シーン・貼り付けたJSON）から変えたセクションには印が付き、↺ でそのセクションだけ元に戻せます**
- スライダーを**ダブルクリック**すると、その項目だけ元に戻ります
- 数値を**クリック**すると直接入力できます（Enter で確定、Esc で取り消し）
- 開いているタブとセクションは、次に開いたときも維持されます

## デザイナー向け：シーンを作って書き出す

テスターの **シーン** タブで、複数のアートを保存して切り替え・モーフの確認ができます。

1. `nenrin-lineart-tester.html` をブラウザで開く
2. プリセットやパラメーターで好きな絵を作る
3. シーン名を入れて「＋ 現在を保存」
4. 2〜3 と繰り返して複数シーンを登録
5. シーン名のボタンを押すと、そのシーンへ実際に遷移します

保存したシーンはブラウザに残ります（v1 とは別に保存されます）。

| 表示 | 意味 |
|---|---|
| **M** バッジ | 構造が一致していて、そのまま **モーフ**で繋がる |
| **F** バッジ | 構造は違うが **強制モーフ**で繋ぐ（既定でON） |
| **×** バッジ | 強制モーフOFF かつ構造が違うため **クロスフェード**になる |
| **⇄** | そのシーンに構造を揃える（M 化）。アイコンも構造なので揃えられます |
| **⟳** | 現在の絵でそのシーンを上書き |
| **×**（右端） | 削除 |

### アイコンを読み込む

アートタブの「中心のアイコン」セクションで「SVG を読み込む」。基準半径が小さいとアイコンが見えないため、40 未満なら自動で 90 にし、全体の大きさが変わらないようスケールを合わせます。「ハート（サンプル）」ですぐ試せます。

### いま効かない項目は隠れます

アートタブの「いま効かない項目を隠す」（既定ON）で、描画に影響しない項目は自動的に隠れます。

| 状況 | 効かなくなる項目 |
|---|---|
| アイコンなし | アイコンの効き |
| 中心の線幅が 1（外周と同じ） | 変化のカーブ |
| 太くする間隔・方向の抑揚・筆圧のゆらぎが 0 | それぞれの量・角度・細かさ |
| 外形のうねりが 0 | うねりの数・外側への増え方 |
| 細かな揺らぎが 0 | 周波数・揺らぎ幅のばらつき・ドリフト（うねりも 0 なら揺らぎ速度も） |
| 常時アニメーション OFF | 各速度 |
| 各「量」が 0 | その周波数・速度（例：波紋の振幅が0なら本数と速度） |
| 変形が効かない（強さ0、またはマウス変形OFFでマウス追従） | 変形の半径・種類・アンカー |
| マウス連動 OFF | 連動の強さ |

### 書き出し

書き出しタブの「実装用コードを書き出し」。

- **シーンが保存されている場合** — 全シーンをまとめて書き出します。どのシーン同士がモーフ／クロスフェードになるかの一覧表もコメントで付きます。`NENRIN_SCENES` オブジェクト経由で参照できます
- **シーンが無い場合** — 画面に出ている絵だけを、指定した名前で書き出します

書き出したコードを `nenrin-runtime.js` と一緒に実装者へ渡してください。
