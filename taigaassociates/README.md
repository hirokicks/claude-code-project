# TAIGA ASSOCIATES — 年輪ラインアート

バージョンごとにフォルダを分けています。各フォルダは単体で完結しているので、
実装者へ渡すときはフォルダごと渡してください。

| | 状態 | 中身 |
|---|---|---|
| [`v1/`](v1/) | **凍結**（2026-10-02） | 記録用のスナップショット。編集しません |
| [`v2/`](v2/) | **作業中** | 現行の開発版。調整はこちらで行います |

v1 の時点で入っているもの — 18プリセット、4線種（シンプル／ブラー／インク／水彩）、
形状ターゲット8種、シーン保存とモーフ確認、実装用コードの書き出し。
詳細は各フォルダの `README.md` を参照してください。

## ローカルで開く

```
npx serve taigaassociates
```

`http://localhost:3000/v2/nenrin-lineart-tester.html` でジェネレーターが開きます。

## そのほか

`concentric-simulator.html` は年輪ラインアート以前の同心円シミュレーターで、
バージョン管理の対象外です。
